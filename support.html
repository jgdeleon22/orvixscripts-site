Getting started

Pulse is a smartphone for ESX Legacy servers. It's one resource, pulse_phone, and it sets up its own database tables. New here? Start with the install guide, then come back for the details.

Install guideUp and running in five steps ConfigurationEvery option in config.lua TroubleshootingFixes for common problems

Installation

  1. Make sure es_extended, oxmysql, ox_lib and pma-voice are running. Add screenshot-basic if you want the camera.
  2. Copy the pulse_phone folder into resources.
  3. Add ensure pulse_phone to server.cfg, after the resources above.
  4. Turn off any other phone resource.
  5. Start the server. There's nothing to import: the tables are created on first start.
TipThe full walkthrough with copy-ready lines is on the Install page.

Camera & voice memos

Photos and voice memos are stored on FiveManage. Create a token in your FiveManage dashboard, then add it to server.cfg:

server.cfg
set pulse_fivemanage_token "your-token"
Use setNever use setr for the token. setr sends it to every player's game, where anyone could copy it.

Uploads happen from the server, so players never see the token. Photo settings (folder, jpg or webp, quality, cooldown, gallery limit) are in Config.Photos. Voice memos also need players to allow microphone access in FiveM.

Phone item & key

By default players need a phone or iphone item. Change the names in Config.PhoneItems, or set Config.RequireItem = false so everyone has a phone.

The phone opens with F1. Change the default with Config.OpenKey. Players can pick their own key in GTA Settings › Key Bindings › FiveM.

Services & 911

The Services app sends a request to everyone on duty in a job. Each entry in Config.Services needs a job name that matches your ESX job exactly:

config.lua
Config.Services = {
    { job = 'police',    label = 'Police',   icon = 'shield', color = '#2563eb' },
    { job = 'ambulance', label = 'EMS',      icon = 'cross',  color = '#dc2626' },
    { job = 'mechanic',  label = 'Mechanic', icon = 'wrench', color = '#f59e0b' },
    { job = 'taxi',      label = 'Taxi',     icon = 'car',    color = '#ca8a04' },
}
Config.EmergencyNumbers = { ['911'] = 'police', ['912'] = 'ambulance' }

Dialing 911 or 912 on the keypad opens a Police or EMS request instead of a call. The player's location is read by the server.

Updating

Copy the new files over the old ones, then run refresh and restart pulse_phone in the server console. Your players' data stays in the database, and new tables or columns are added automatically.

Developer exports

Send texts, mail, notifications and bank history from your own scripts. The full list with examples is on the Specs page. The most used:

server.lua
exports.pulse_phone:SendMessage('Fleeca', '555-1234', 'Your loan was approved')
exports.pulse_phone:Notify(source, { app = 'bank', title = 'Fleeca', text = 'Payment received' })

Troubleshooting

The phone won't open when I press F1

Check the player has a phone or iphone item, or set Config.RequireItem = false. If they changed the key in GTA's Key Bindings, F1 won't work for them anymore. Also make sure no other phone resource is running.

Photos won't take or upload

Make sure screenshot-basic is started and the token is set with set pulse_fivemanage_token in server.cfg. Restart the server after adding it. Check the server console for a FiveManage error message.

Calls connect but there's no voice

Pulse uses pma-voice call channels starting at Config.CallChannelOffset (5000). Make sure pma-voice starts before Pulse, and that no radio script uses the same channel numbers.

Nobody gets service requests

The job names in Config.Services must match your ESX job names exactly, and the player has to be on duty in that job.

I updated Pulse and something's missing

Run refresh before restart pulse_phone. Without it, FiveM ignores newly added files.

Voice memos don't record

Voice memos need the FiveManage token and the player's microphone allowed in FiveM's settings.

FAQ

Does Pulse work with QBCore?

Not right now. Pulse is built for ESX Legacy.

Do I need to import an SQL file?

No. Pulse creates and updates its own tables when it starts.

Can I remove apps I don't want?

Yes. Players can remove and re-add apps from their home screen with the App Store app.

Can players see each other's phone numbers on Chirp or Lens?

No. Numbers are never shown on the social apps.

Where do I buy Pulse?

Pulse will be sold on Tebex at launch. It's in final testing now.

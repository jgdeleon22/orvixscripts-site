Getting started

Orvix Characters is one resource, orvix_characters, for ESX Legacy or QBCore. It needs oxmysql and ox_lib, and works with illenium-appearance, fivem-appearance, qb-clothing, esx_skin / skinchanger or crm-appearance.

Installation

  1. Remove your old multicharacter

    Stop esx_multicharacter, qb-multicharacter, crm-multicharacter or similar, and qb-spawn on QBCore. Only one character screen can run.

  2. Copy and ensure

    Put orvix_characters in resources and add it after your framework:

    server.cfg
    ensure orvix_characters

  3. ESX only: turn on multichar

    In es_extended/shared/config/main.lua:

    config.lua
    Config.Multichar = true

  4. Start the server

    Tables are created automatically. Existing characters show up as they are.

Scenes & spots

Each scene has stands where characters wait, an overview camera and optional interiors. If a character floats or stands in a wall, stand where they should be, type /ocpos and paste the line into Config.Scenes. Spawns and the dressing room work the same way.

Look studio

After the ID card, new characters build their look in a private dressing room, then pick a spawn. The look is saved where your clothing script reads it. Admins get a Copy outfit for config button that prints a ready-to-paste starter outfit in F8. Set Config.Studio.Enabled = false to skip it, or ThenOpenFullCreator = true to also open your clothing script after spawning.

Starter pack & apartments

Config.Starter sets where new characters may spawn, starter apartments (plain spawns, qb-apartments or ps-housing), and a one-time pack of cash, bank money and items.

config.lua
Config.Starter = {
  Cash = 500, Bank = 2500,
  Items = { { name = 'phone', count = 1 }, { name = 'water', count = 2 } },
  ApartmentSystem = 'none',  -- or 'qb-apartments', 'ps-housing'
}

Discord & logs

Optional. Use set, never setr.

server.cfg
set orvix_characters_webhook "https://discord.com/api/webhooks/..."  # create, delete, CK logs
set orvix_discord_token "your-bot-token"  # extra slots from Discord roles

Then turn on Config.DiscordRoles and map role IDs to extra slots.

Troubleshooting

Players spawn straight in without the character screen

Another multicharacter or spawn script is still running, or on ESX Config.Multichar is still false.

Characters stand in default clothes

Check your clothing script is started before orvix_characters and that it saves to users.skin (ESX) or playerskins (QBCore).

A character floats or is inside a wall

Stand where they should be, use /ocpos, and paste the line over that stand in Config.Scenes.

Getting started

Orvix HUD is one resource, orvix_hud, for ESX Legacy or QBCore. It needs ox_lib. pma-voice and a fuel script are optional; it finds them on its own.

Installation

  1. Stop your old HUD

    Remove other HUDs and speedometers (esx_hud, qb-hud, ps-hud and similar) so two don't draw on top of each other.

  2. Copy and ensure

    Put orvix_hud in resources and add it after your framework:

    server.cfg
    ensure orvix_hud

  3. Pick your default look

    Set Config.Default to your server's style and accent color. Players can change their own with /hud.

Commands & keys

Command or keyWhat it does
/hudOpen HUD settings and Edit layout
/cinematicHide the HUD and add black bars
BSeatbelt on or off
CCruise control at your current speed (brake to cancel)

Keys can be changed by each player in Settings › Key Bindings › FiveM.

Notifications

With Config.ReplaceNotify on, ox_lib, ESX and QBCore notifications show in the Orvix HUD style automatically. You can also call it yourself:

client
exports.orvix_hud:Notify('success', 'Vehicle stored', 'Your car is in the garage.', 5000)
-- types: success, error, info, warning, phone
server
TriggerClientEvent('orvix_hud:notify', source, 'info', 'Paycheck', 'You were paid $650.')

Progress & prompts

client
local done = exports.orvix_hud:Progress('Lockpicking vehicle', 4000, { canCancel = true })
if done then -- finished, not cancelled end

exports.orvix_hud:HelpText('E', 'Open garage')   -- show
exports.orvix_hud:HelpText(false)                  -- hide

Troubleshooting

Two HUDs show at once

Another HUD or speedometer is still running. Stop it in server.cfg.

Hunger and thirst stay at 100

On ESX make sure esx_status and esx_basicneeds are started before orvix_hud.

Fuel always shows full

Set Config.Fuel to the fuel script you run instead of 'auto'.

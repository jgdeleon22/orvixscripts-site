FAQ

Questions about Orvix HUD

Where do hunger, thirst and stress come from?

On ESX it reads esx_status; on QBCore it reads the player's metadata. It detects which one you run.

Which fuel scripts work?

LegacyFuel, ox_fuel, cdn-fuel and ps-fuel, or the game's own fuel level if you run none.

Does it replace my seatbelt script?

It has a seatbelt built in (B by default). If you already run one, turn ours off in the config and the light follows yours.

Can I lock the style for everyone?

Yes. Set your server's default look in the config and choose which settings players are allowed to change.

When is it out?

Orvix HUD is in development. The docs show what the launch version will do.

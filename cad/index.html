FAQ

Questions about Orvix CAD

Do I need a separate website or hosting?

No. The dispatcher website is served by your FiveM server itself. For a nice address with HTTPS, put it behind Cloudflare or a reverse proxy; the docs show how.

How do dispatchers sign in?

Staff create a personal key for each dispatcher with one command. Keys are stored scrambled and can be removed any time.

Does it work without Orvix Pulse?

Yes. With Orvix Pulse, 911 and 912 calls land on the board automatically. Without it, calls come from alerts, officers and dispatchers, and any script can create one with an export.

Which jail script does it use?

Any. There's a one-line hook in the config with examples for common jail scripts.

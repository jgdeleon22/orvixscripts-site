FAQ

Before you buy

Which frameworks are supported?

ESX Legacy and QBCore. Both scripts detect which one you run when they start.

Is this a subscription?

No. You pay once per server and get every update for that script.

Can I change how things work?

Yes. Prices, jobs, ranks, keys, locations and limits all live in open config files, and the docs list every option.

Do I need both scripts?

No. Each one works on its own. Together they share data: for example, Admin can look up a player's Pulse number in a report.

When can I buy?

Checkout opens through Tebex at launch. Pulse is in final in-city testing, with Orvix Admin coming after it.

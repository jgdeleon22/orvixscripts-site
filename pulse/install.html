Install Pulse

Most servers are running in under ten minutes. Pulse works out whether you run ESX Legacy or QBCore and creates its own database tables.

Before you start

Required · one ofes_extended · qb-core

ESX Legacy 1.12+ or QBCore. Detected automatically.

Requiredoxmysql

Database driver. Tables are created for you.

Requiredox_lib

Callbacks and shared helpers.

Requiredpma-voice

Voice for phone calls.

For camerascreenshot-basic

Plus a FiveManage token or a Discord webhook for photos and voice memos.

Optionalcd_garage · billing · inventories

Garage spots, esx_billing or QBCore invoices, ox_inventory or qs-inventory.

Step by step

  1. Copy the folder

    Put orvix_pulse in your resources folder. Keep the name exactly orvix_pulse.

  2. Add it to server.cfg

    After your framework, oxmysql, ox_lib and pma-voice:

    server.cfg
    ensure orvix_pulse

  3. Add your upload method

    Turns on Camera, Photos, Blink and Voice Memos. FiveManage token below, or a Discord webhook (see the docs). Use set, never setr.

    server.cfg
    # server-only: players never see this
set pulse_fivemanage_token "your-token"

  4. Turn off your old phone

    Only one phone resource can run at a time. Comment out the old one.

  5. Start the server

    The console shows [orvix_pulse] framework: QBCore or ESX Legacy. Give a player a phone item and press F1.

Updating to a new version

Copy the new files over the old ones, then run these in the server console. Without refresh, newly added files are ignored.

server console
refresh
restart orvix_pulse

Want to change fares, restaurants, the phone item or which jobs can drive? The docs cover every option.

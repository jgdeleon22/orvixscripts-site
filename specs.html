Security

  • Every action is checked on the server. The phone screen can only reach a fixed list of actions.
  • Photos and voice memos upload from the server, so your FiveManage token never reaches players.
  • Phone numbers are never shown on Chirp or Lens.
  • Players can only send photos from their own gallery, never outside links.
  • Service request locations are read by the server, so they can't be faked.

Developer exports

Let your jobs, banks and shops talk to players through the phone.

server exports
exports.pulse_phone:GetNumber(source)
exports.pulse_phone:GetSourceByNumber('555-1234')
exports.pulse_phone:HasPhone(source)
exports.pulse_phone:IsInCall(source)
exports.pulse_phone:SendMessage('Fleeca', '555-1234', 'Your loan was approved')
exports.pulse_phone:Notify(source, { app = 'bank', title = 'Fleeca', text = 'Payment received' })
exports.pulse_phone:LogTransaction(source, 2500, 'Paycheck')
exports.pulse_phone:SendMail(source, { sender = 'LSPD', subject = 'Ticket issued', body = 'You were fined $150.' })
client exports
exports.pulse_phone:IsOpen()
exports.pulse_phone:Open()
exports.pulse_phone:Close()

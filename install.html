Install Pulse

Most servers are running in under ten minutes. There's no SQL to import: Pulse creates its own database tables the first time it starts.

Before you start

Requiredes_extended

ESX Legacy 1.12 or newer.

Requiredoxmysql

Database driver. Tables are created automatically.

Requiredox_lib

Callbacks and shared helpers.

Requiredpma-voice

Voice for phone calls.

For camerascreenshot-basic

Plus a FiveManage token for photos and voice memos.

Optionalesx_billing · cd_garage

Bills in the Bank app, garage spots in the Garage app.

Step by step

  1. Copy the folder

    Put the pulse_phone folder in your server's resources folder. Keep the folder name exactly pulse_phone.

  2. Add it to server.cfg

    Add this line after pma-voice, ox_lib and oxmysql:

    server.cfg
    ensure pulse_phone

  3. Add your FiveManage token

    This turns on the Camera, Photos and Voice Memos. Use set, never setr: setr sends the value to every player.

    server.cfg
    # server-only: players never see this
set pulse_fivemanage_token "your-token"

  4. Turn off your old phone

    Only one phone resource can run at a time. Comment out the old one, for example ensure [smartphone] for qs-smartphone.

  5. Start the server

    Pulse creates its tables on first start. Give a player a phone or iphone item and press F1.

Updating to a new version

Copy the new files over the old ones, then run these in the server console. Without refresh, any newly added script files are ignored.

server console
refresh
restart pulse_phone

Stuck, or want to change the phone item, key or services? The support docs cover every option.
